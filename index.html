Bienvenu sur le site internet du jeu vidéo Neon Nexus.


Pour naviguer entre les différentes pages du site, vous pouvez clicker sur le petit vaisseau en haut à gauche.
Neon Nexus est un jeu de type Space Shooter crée avec python muni du moteur graphique pyxel.

Pour pouvoir y jouer vous devrez tout d'abord installer le jeu qui se trouve sur la page Télécharger.
Ensuite, pour pouvoir jouer vous devrez suivre les étapes d'istallation requises au bon fonctionnement du jeu qui se trouvent dans la page Jouer.
