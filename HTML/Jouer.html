Comment Jouer?

Installation :

Pour pouvoir jouer au jeu Neon Nexus, vous deverez équiper votre machine de python et du moteur de jeu pyxel.
Dès que vous avez fini de suivre toutes les étapes d'installation vous pouvez lancer le programme python et vous pourrez alors enfin jouer au jeu Neon Nexus.

Commandes de Jeu :

  • Lancer le Jeu : Tab
  • Avancer : ↑
  • Reculer : ↓
  • Aller à droite : →
  • Aller à gauche : ←
  • Tirer : Espace
